# What's Popping (Web)

Polished web version of the nightlife discovery app.

## Live Demo
Enable GitHub Pages on this repo (Settings → Pages → Deploy from branch → main / /web) and it will be live at:

https://k4rawan.github.io/whats-popping/

## Features
- Full-screen dark hybrid UI
- Map home with place pins + friend symbols
- Live Feed
- Events (public + private parties)
- Messages (including read-only groups)
- Profile + Create Private Party modal

Open `index.html` locally or host on GitHub Pages.
