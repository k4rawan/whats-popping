# What's Popping (Web)

Polished web version of the nightlife discovery app.

## Live Demo

The published copy is [`docs/index.html`](../docs/index.html), not this folder.

Live URL: https://k4rawan.github.io/whats-popping/

GitHub Pages cannot publish `/web`. Settings must be:

- Source: Deploy from a branch
- Branch: main
- Folder: **/docs**

Settings page: https://github.com/k4rawan/whats-popping/settings/pages

## Features

- Full-screen dark hybrid UI
- Map home with place pins + friend symbols
- Live Feed
- Events (public + private parties)
- Messages (including read-only groups)
- Profile + Create Private Party modal

Keep `web/index.html` and `docs/index.html` in sync. Only `docs/` is what GitHub Pages serves.
